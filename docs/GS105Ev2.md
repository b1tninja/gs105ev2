# Device identification — NETGEAR GS105Ev2

## Model confirmation

- **Model:** GS105Ev2 — NETGEAR's "5-Port Gigabit Ethernet Easy Smart
  Switch", marketed under both the "Plus"/"Smart Managed Plus" and (older)
  "ProSAFE Plus" lines depending on region/era of NETGEAR's site.
  Dimensions 94x100x27 mm, no PoE budget, external 12VDC/1A adapter, fanless.
  (NETGEAR product pages, e.g. netgear.com/.../switches/plus/gs105ev2/.)
- The "v2" is a hardware/firmware-generation suffix distinct from "GS105E"
  (v1, EOL, different firmware line) and from "GS105PE" (PoE variant, shares
  much of the v2 firmware/utility story). **Confirm the exact unit in hand**
  by reading the label on the bottom of the switch (model + serial) once it
  is available, and cross-check against the EU Declaration of Conformity:
  `204-11412-06_CE_GS105Ev2_EN-EP-FR-IT-GR-SP_20May25.pdf` (NETGEAR download
  site) for the regulatory/hardware revision on file as of 2025.
- This project targets **GS105Ev2 specifically**; GS105E (v1) and GS105PE
  firmware/utilities are a different download tree and are out of scope
  unless the physical unit turns out to be one of those instead.

## Management

- **Web UI:** served by the switch itself once it has an IP (DHCP, or a
  NETGEAR-documented static fallback if no DHCP server responds — confirm
  exact fallback behavior against the unit; NETGEAR's manual is the
  authoritative source and was not mirrored here, see "Gaps" below).
- **NSDP (NETGEAR Switch Discovery Protocol):** proprietary UDP
  broadcast/response protocol on ports 63321-63324, used by both NETGEAR's
  own utilities and third-party tools to find the switch, read its model/MAC/
  IP, and (historically) push configuration. Full protocol notes:
  [`NSDP-PROTOCOL.md`](NSDP-PROTOCOL.md). **Removed from the switch's side
  starting firmware 1.6.0.15** — see the caveat in
  `../downloads/firmware/README.md`.
- **Official utilities:** the current one is the **NETGEAR Discovery Tool
  (NDT)**, v2.0.4 as of this writing, which speaks UPnP and (on older
  firmware) NSDP. The **ProSAFE Plus Configuration Utility** (sometimes
  called "Smart Control Center" in older NETGEAR materials) is the
  predecessor Windows-only tool, still documented for firmware before
  1.6.0.15, requiring utility version >= V2.7.2 for firmware >= 1.6.0.3.
  See [`../downloads/utilities/README.md`](../downloads/utilities/README.md).

## Hardware / chipset

**Confirmed from firmware strings** (see
[`FIRMWARE-FORMAT.md`](FIRMWARE-FORMAT.md)): both the current (1.6.0.25) and
2019-era (1.6.0.4) firmware images contain the plaintext string
`RTL8367N` repeatedly (e.g. in a version/build info block alongside the
build date), plus one occurrence of `RTL8367B` — so the switch silicon is a
**Realtek RTL8367N** (an 8x1000M-class integrated switch/PHY SoC), probably
with RTL8367B as a related/alternate-SKU part the same firmware tree
supports. This supersedes the earlier "reasonable working assumption" below,
which was based only on comparable products' teardowns and is now
corroborated directly. Still not independently verified by opening the case
or by an FCC-filing photo — "the chip says so in its own firmware" is strong
but not a substitute for physical confirmation if that matters later.

Related consumer-class NETGEAR/Cisco switches in this size/price bracket
(GS208, GS108Tv3, Cisco SG110D-08) also use Realtek switch SoCs (RTL8370N or
RTL8380M-class parts) — consistent with, though not identical to, the
RTL8367N found here. See [`research.md`](research.md) for sources.

**Management CPU core — confirmed 8051-family** (distinct from the
RTL8367N switch silicon above, which is a separate switch-fabric chip the
8051 drives over its register interface): a Ghidra pass disassembled the
firmware's real reset vector into a clean, self-consistent 8051 instruction
chain. See [`GHIDRA-NOTES.md`](GHIDRA-NOTES.md).
